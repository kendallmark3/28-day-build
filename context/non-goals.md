# Non-Goals

- This is not a Claude chat clone.
- This is not an autonomous agent platform.
- This is not an enterprise workflow engine.
- This does not store credentials or call AI APIs from browser code.
- This project should demonstrate the method before adding platform complexity.
- This app does not connect to Jira: no API, no import by URL, no file upload. The user pastes text.
- The Jira story analysis is fixed rules, not AI, and it does not rewrite or fix the user's story.
- Comparing stories, or refining an intent from a second story, is not part of the current round.
- Feature-level non-goals are kept in `intent/current-feature.md`.
