# 3-Minute Demo Script

1. **Problem (20 sec):** Good AI work disappears into chat history. IntentWorkbench turns it into durable engineering assets.
2. **Intent (35 sec):** Open Intent Builder. Show outcome, inputs, outputs, constraints, success criteria, stop condition.
3. **Context (25 sec):** Show curated project context and non-goals.
4. **Evidence (35 sec):** Show observed/inferred/assumed claims and the readiness check.
5. **Guardrails (25 sec):** Change consequence level and show verification expectations.
6. **Capability (25 sec):** Promote repeated work into a reusable capability.
7. **Close (15 sec):** Show 28-day progress and explain the loop: Intent → Result → Evidence → Refined Intent → Better Result.
